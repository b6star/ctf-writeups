The Troll's Ticket

AUTHOR pri4cy

Congratulations on winning the Indian Railways Golden Diamond Tour!

Unfortunately, someone has tampered with your ticket. Your journey passes through Delhi, Mumbai, Chennai, and Kolkata, but the files may not be what they appear to be.

Follow the trail, recover your ticket, and claim your prize.

Indian Railways Golden Diamond Tour에 당첨된 것을 축하한다!

누군가 승차권을 조작했다. 여정은 Delhi, Mumbai, Chennai, Kolkata를 지나지만, 파일의 겉모습을 그대로 믿어서는 안 된다.

흔적을 따라 승차권을 복구하고 상품을 받아라.

Write Up

Starting from the Challenge

Extracting challenge_1.zip produces IRCTC_Tatkal_Hack.pdf, outer_wordlist.txt, and README.txt. I tried opening the PDF first, but it would not open. The README also says 'The files left behind may not be what they appear to be.', so I checked the file signature.

file IRCTC_Tatkal_Hack.pdf

Its actual format was an encrypted ZIP archive. I changed the extension to .zip.

1. Opening the file that only looks like a PDF

outer_wordlist.txt contains one password candidate per line and sits beside the disguised, encrypted ZIP.

Q: Which locked file is this outer password list meant to open?

At this stage, the disguised ZIP is the only locked file, so I used the list against it.

Using Python's zipfile module, I tried each value from the list as the password. The 62,868th candidate, railwaystationroyaljourney, extracted the archive and produced README.txt, delhi.jpg, and delhi_wordlist.txt.

2. Following the city images and wordlists

Inside the ZIP, the README, wordlist, and file arrangement matched the previous stage except that the PDF had been replaced by delhi.jpg, so I suspected another archive was hidden inside the file. The city names in delhi.jpg and delhi_wordlist.txt matched, and the README said 'Once inside, inspect your files carefully. Appearances can be deceiving.', so I checked the internal signature. I found a ZIP after the JPEG data and tried the candidates from delhi_wordlist.txt with Python's zipfile module. It opened with cholebhature and contained delhi.txt, mumbai.jpg, and mumbai_wordlist.txt.

delhi.txt said, 'The wordlist from this stage belongs to the next journey. Keep following the trail.' I continued extracting the next item with the wordlist provided alongside each extracted image.

Target image Candidate list Password Next image
delhi.jpg delhi_wordlist.txt cholebhature mumbai.jpg
mumbai.jpg mumbai_wordlist.txt vada_pav chennai.jpg
chennai.jpg chennai_wordlist.txt mylapore kolkata.jpg
mumbai.txt also instructed, 'Look for data beyond its visible contents and identify the archive hidden inside.' I proceeded in the order Delhi → Mumbai → Chennai → Kolkata, extracting the ZIP appended to each image.

3. Recovering the final ticket from Kolkata

chennai.txt said, 'Inspect the image carefully. The next archive may be hiding beyond the picture itself.' Checking kolkata.jpg showed that this time an encrypted PDF had been appended after the JPEG. I separated the data from the %PDF starting position through the end.

# extract_ticket.py — written for this write-up
from pathlib import Path

data = Path("kolkata.jpg").read_bytes()
Path("kolkata.pdf").write_bytes(data[data.index(b"%PDF"):])

The PDF password was also found in the provided outer_wordlist.txt: the 56,890th candidate, peacock. Opening the PDF with this value displayed a ticket showing the Delhi → Mumbai → Chennai → Kolkata journey, with the flag written underneath.

문제에서 출발하기

challenge_1.zip을 풀면 IRCTC_Tatkal_Hack.pdf, outer_wordlist.txt, README.txt가 나온다. 먼저 PDF를 열어봤는데 열리지 않았다. README에도 'The files left behind may not be what they appear to be.'라는 문구가 있어 파일 시그니처를 확인했다.

file IRCTC_Tatkal_Hack.pdf

실제 형식은 암호화된 ZIP이었다. 확장자를 .zip으로 바꿨다.

1. PDF처럼 보이는 ZIP 열기

outer_wordlist.txt를 열면 비밀번호 후보가 한 줄에 하나씩 있고, PDF로 위장한 암호화 ZIP과 같은 위치에 있다.

Q: 이 바깥쪽 비밀번호 목록은 어느 잠긴 파일을 열기 위한 것일까?

이 단계에서 잠긴 파일은 위장한 ZIP 하나뿐이므로 여기에 후보를 넣었다.

Python의 zipfile 모듈로 목록의 값을 하나씩 비밀번호로 대입했다. 62,868번째 후보인 railwaystationroyaljourney로 압축이 풀렸고, README.txt, delhi.jpg, delhi_wordlist.txt가 나왔다.

2. 도시 이미지와 wordlist 따라가기

압축을 풀고 보니 README와 wordlist가 다시 나왔고, 앞 단계의 PDF 자리에는 delhi.jpg가 있었다. 같은 구조가 반복된 점과 delhi.jpg, delhi_wordlist.txt의 도시 이름이 일치하는 점을 보고 이미지 안에 다음 압축 파일이 있을 것으로 의심했다. README에도 'Once inside, inspect your files carefully. Appearances can be deceiving.'라고 적혀 있어 내부 시그니처를 확인했다. JPEG 데이터 뒤에서 ZIP을 찾았고, Python의 zipfile 모듈로 delhi_wordlist.txt의 후보를 대입하자 cholebhature로 열렸다. 안에는 delhi.txt, mumbai.jpg, mumbai_wordlist.txt가 있었다.

delhi.txt에는 'The wordlist from this stage belongs to the next journey. Keep following the trail.'이라고 적혀 있었다. 이후에도 추출된 이미지와 함께 나온 wordlist를 사용해 다음 자료를 꺼냈다.

대상 이미지 후보 목록 비밀번호 다음 이미지
delhi.jpg delhi_wordlist.txt cholebhature mumbai.jpg
mumbai.jpg mumbai_wordlist.txt vada_pav chennai.jpg
chennai.jpg chennai_wordlist.txt mylapore kolkata.jpg
mumbai.txt에도 'Look for data beyond its visible contents and identify the archive hidden inside.'라는 안내가 있었다. 각 이미지에 붙은 ZIP을 풀면서 Delhi → Mumbai → Chennai → Kolkata 순서로 진행했다.

3. Kolkata에서 최종 승차권 복구하기

chennai.txt에는 'Inspect the image carefully. The next archive may be hiding beyond the picture itself.'라고 적혀 있었다. kolkata.jpg를 확인하니 이번에는 JPEG 뒤에 암호화된 PDF가 붙어 있었다. %PDF 시작 위치부터 끝까지 분리했다.

# extract_ticket.py — written for this write-up
from pathlib import Path

data = Path("kolkata.jpg").read_bytes()
Path("kolkata.pdf").write_bytes(data[data.index(b"%PDF"):])

PDF 비밀번호도 제공된 outer_wordlist.txt에서 찾았으며, 56,890번째 후보인 peacock이었다. 이 값으로 PDF를 열자 Delhi → Mumbai → Chennai → Kolkata 여정이 적힌 승차권이 나왔고, 그 아래에 Flag 가 적혀있었다.
