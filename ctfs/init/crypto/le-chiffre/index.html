Write Up

Starting from the Challenge

The ciphertext comes with the hint 'The key is the hour when everything goes quiet.' That made me think of MIDNIGHT. I checked this candidate against the known flag prefix, InIt.

UvLg{d1m3u3k3_i4a_q0g_bn3_4uli3z}

1. Checking MIDNIGHT against the known prefix

In a Vigenère cipher, each key letter gives a shift. With A=0 through Z=25, subtracting the known plaintext from the ciphertext gives the key value at that position. I compared UvLg with InIt:

Ciphertext Plaintext Difference mod 26 Key letter
U I 12 M
v n 8 I
L I 3 D
g t 13 N

The differences spell MIDN, matching the first four letters of MIDNIGHT. I used the full eight-letter candidate to decrypt the rest.

2. Advancing the key only on letters

Vigenère decryption subtracts the key value from the ciphertext value, then takes the result modulo 26 to wrap around the alphabet. The key repeats from M after all eight letters of MIDNIGHT have been used.

The prefix UvLg uses MIDN. For the next fragment, d1m, key letter I turns d into v; 1 stays unchanged; then key letter G turns m into g. Digits, underscores, and braces stay unchanged, and the key advances each time a letter is processed.

3. Decrypting the full string

# solve.py — written for this write-up
ciphertext = "UvLg{d1m3u3k3_i4a_q0g_bn3_4uli3z}"
key = "MIDNIGHT"
out = []
ki = 0

for ch in ciphertext:
    if ch.isalpha():
        base = ord("A") if ch.isupper() else ord("a")
        shift = ord(key[ki % len(key)]) - ord("A")
        out.append(chr((ord(ch) - base - shift) % 26 + base))
        ki += 1
    else:
        out.append(ch)

print("".join(out))

ki counts the letters processed, and ki % len(key) selects the repeating key letter. Choosing the base from the character's case preserves uppercase and lowercase letters. The script prints the flag below.

Final Flag

InIt{v1g3n3r3_w4s_n0t_th3_4nsw3r}

문제에서 출발하기

암호문과 함께 'The key is the hour when everything goes quiet.'라는 힌트가 주어진다. 이 표현에서 자정을 뜻하는 MIDNIGHT를 떠올렸다. 이를 키 후보로 두고, 알려진 플래그 접두부 InIt와 비교했다.

UvLg{d1m3u3k3_i4a_q0g_bn3_4uli3z}

1. 알려진 접두부로 MIDNIGHT 확인하기

Vigenère 암호에서는 키의 각 글자가 이동할 칸 수를 정한다. 알파벳을 A=0부터 Z=25까지 숫자로 놓고 암호문에서 알려진 평문을 빼면 해당 위치의 키 값을 구할 수 있다. UvLg와 InIt를 비교했다.

암호문 평문 차이 mod 26 키 글자
U I 12 M
v n 8 I
L I 3 D
g t 13 N

차이를 문자로 읽으면 MIDN으로, MIDNIGHT의 앞 네 글자와 일치한다. 이 8글자 키 후보로 나머지 문자열을 복호화했다.

2. 알파벳에서만 키 위치 이동하기

Vigenère 복호화는 암호문 값에서 키 값을 빼고, 26으로 나눈 나머지를 구해 알파벳 범위 안에서 순환시킨다. MIDNIGHT의 8글자를 모두 쓰면 다시 M부터 반복한다.

접두부 UvLg에는 MIDN을 사용한다. 다음 부분인 d1m에서는 키 글자 I로 d를 v로 바꾸고, 1은 그대로 둔 뒤, 키 글자 G로 m을 g로 바꾼다. 숫자와 밑줄, 중괄호는 그대로 두고 알파벳을 처리할 때마다 키를 한 글자씩 진행한다.

3. 전체 문자열 복호화하기

# solve.py — written for this write-up
ciphertext = "UvLg{d1m3u3k3_i4a_q0g_bn3_4uli3z}"
key = "MIDNIGHT"
out = []
ki = 0

for ch in ciphertext:
    if ch.isalpha():
        base = ord("A") if ch.isupper() else ord("a")
        shift = ord(key[ki % len(key)]) - ord("A")
        out.append(chr((ord(ch) - base - shift) % 26 + base))
        ki += 1
    else:
        out.append(ch)

print("".join(out))

ki는 처리한 알파벳 수를 세고, ki % len(key)는 반복해서 사용할 키 글자를 고른다. 문자의 대소문자에 따라 기준값을 정해 대소문자도 유지한다. 코드를 실행하면 아래 플래그가 출력된다.
