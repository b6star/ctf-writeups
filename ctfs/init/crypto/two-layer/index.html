Two Layers

AUTHOR Harsh Agarwal

We intercepted this string from a careless admin. He swore he'd "double-encoded it for safety." Prove him wrong.

VmFWZ3tlMGdfZ3UzYV9vNjRfMWZfYTBnX2YzcGhlMWdsfQ== Flag format: InIt{...}

부주의한 관리자의 문자열을 가로챘다. 그는 '안전을 위해 두 번 인코딩했다'고 장담했다. 그의 주장이 틀렸음을 증명하라.

VmFWZ3tlMGdfZ3UzYV9vNjRfMWZfYTBnX2YzcGhlMWdsfQ== 플래그 형식: InIt{...}

FLAG FORMATInIt{...}

Write Up

Starting from the Challenge

The admin says he “double-encoded it for safety” and gives us this string:

VmFWZ3tlMGdfZ3UzYV9vNjRfMWZfYTBnX2YzcGhlMWdsfQ==

1. Why Base64 first?

The string uses letters and digits and ends in ==, which looks like Base64 padding. Base64 represents bytes as printable characters. I decoded the string and got:

VaVg{e0g_gu3a_o64_1f_a0g_f3phe1gl}

Q: Why does the result start with VaVg?

2. Why ROT13 next?

The flag format is InIt{...}. ROT13 (Rotation 13) turns VaVg into InIt, so I applied it to the whole decoded string. The digits, underscores, and braces stay as they are.

The order follows the text we can see: decode the Base64 string, then run ROT13 on its result.

3. Checking both steps

# solve.py — written for this write-up
import base64
import codecs

encoded = "VmFWZ3tlMGdfZ3UzYV9vNjRfMWZfYTBnX2YzcGhlMWdsfQ=="
layer1 = base64.b64decode(encoded).decode()
flag = codecs.decode(layer1, "rot_13")

print(layer1)
print(flag)

The first line printed is the intermediate string; the second is the flag. Applying ROT13 to the flag and encoding it with Base64 gives back the original input.

Final Flag

InIt{r0t_th3n_b64_1s_n0t_s3cur1ty}

Summary

  • Base64: The == ending led to the first decoding step. Its output was VaVg{e0g_gu3a_o64_1f_a0g_f3phe1gl}.
  • ROT13: VaVg became InIt, so I applied ROT13 to the full string.
  • Flag: InIt{r0t_th3n_b64_1s_n0t_s3cur1ty}

문제에서 출발하기

관리자는 문자열을 'double-encoded it for safety.'라고 설명했다. 주어진 문자열은 다음과 같다.

VmFWZ3tlMGdfZ3UzYV9vNjRfMWZfYTBnX2YzcGhlMWdsfQ==

1. 왜 Base64부터?

문자열은 영문자와 숫자로 이루어져 있고 끝에 ==가 붙어 있다. Base64의 패딩 형태와 같다. Base64는 바이트를 출력 가능한 문자로 표현한다. 문자열을 디코딩하자 다음 값이 나왔다.

VaVg{e0g_gu3a_o64_1f_a0g_f3phe1gl}

Q: 결과가 왜 VaVg로 시작할까?

2. 왜 ROT13인가?

플래그 형식은 InIt{...}이다. VaVg에 ROT13(Rotation 13)을 적용하면 InIt가 되므로, 디코딩한 문자열 전체에 같은 변환을 적용했다. 숫자와 밑줄, 중괄호는 그대로 남는다.

눈앞에 있는 문자열을 Base64로 디코딩하고, 나온 결과에 ROT13을 적용하는 순서다.

3. 두 단계 확인하기

# solve.py — written for this write-up
import base64
import codecs

encoded = "VmFWZ3tlMGdfZ3UzYV9vNjRfMWZfYTBnX2YzcGhlMWdsfQ=="
layer1 = base64.b64decode(encoded).decode()
flag = codecs.decode(layer1, "rot_13")

print(layer1)
print(flag)

첫 줄에는 중간 문자열이, 둘째 줄에는 플래그가 출력된다. 플래그에 ROT13을 적용한 뒤 Base64로 인코딩하면 처음 입력한 문자열이 다시 나온다.

Final Flag

InIt{r0t_th3n_b64_1s_n0t_s3cur1ty}

요약

  • ROT13: VaVg가 InIt로 바뀌는 것을 확인하고 전체 문자열에 ROT13을 적용했다.
  • Flag: InIt{r0t_th3n_b64_1s_n0t_s3cur1ty}
